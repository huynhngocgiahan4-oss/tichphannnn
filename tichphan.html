🚀 Deploy lên GitHub Pages

BƯỚC 01

Tạo GitHub repo

Vào github.com → New repository → Đặt tên (vd: tich-phan) → Create

BƯỚC 02

Upload file

Vào repo → Add file → Upload files → Kéo thả file index.html → Commit changes

BƯỚC 03

Bật GitHub Pages

Settings → Pages → Source: main branch → Save. Chờ ~1 phút là có link!

BƯỚC 04

Chia sẻ link

Link có dạng:
username.github.io/tich-phan
